ORAS Copy Engine Algorithm

Python port of oras-go — interactive walkthrough of the copy DAG traversal

The copy engine copies an OCI content DAG from a source to a destination. An OCI image is a tree: an Index points to Manifests, which point to Config + Layers (blobs). The engine traverses this tree children-first (post-order), so layers arrive before the manifest that references them.
copy() in oras/copy/copy.py — the top-level entry point. Orchestrates 4 steps before handing off to the graph traversal.
copy_graph() in oras/copy/graph.py — initializes concurrency primitives, then kicks off _process_node for the root.
_process_node(region, desc) — the heart of the algorithm. Runs once per node in the DAG. Each node goes through: dedup check → exists check → find children → recurse → copy self.
The concurrency model uses unbounded daemon threads gated by a counting semaphore. LimitedRegion prevents deadlock by letting parents release their slot while waiting for children.
